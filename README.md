stemcraft

🔗 https://stemcraft-psi.vercel.app/

a bouquet arrangement planner. add flowers to your list, hit get an arrangement, and it sends them to an ai model that writes back a full arrangement suggestion, palette, proportion, and meaning included.

what i learned

- react state and forms: holding the flower list in state and rendering it live with .map and keys
- calling an ai model through a serverless function so the api key never ships to the browser
- rendering the markdown the model returns with react-markdown

built with

react, typescript, tailwind, vite, groq, vercel
